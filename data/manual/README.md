# Hand-gathered inputs

Files in this folder are written by hand (or by a research pass) and read by `data/build.py`.
Every row carries its own source URL and the date it was checked.

- `states.json`        — state-level law columns (homeschool, firearms, right-to-farm, rainwater/off-grid, income tax)
- `zoning_state.json`  — state-level zoning pattern per state
- `zoning_verified.json` — counties whose zoning status was confirmed, with the URL it was confirmed from
- `amish.json`         — Amish / Mennonite settlements by county FIPS
- `public_land.csv`    — public land share by county FIPS (if a county-level table was found)
- `broadband.csv`      — FCC broadband availability by county FIPS
